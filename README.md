# DHCP Server Configuration (Cisco Packet Tracer)

A lab where a DHCP server automatically assigns IP addresses, gateways, and DNS to multiple PCs.

How to run
1. Download the .pkt file from this repository.
2. Open it in Cisco Packet Tracer (version 8.2.2).
3. Open any PC > Desktop > IP Configuration > select DHCP to see it get an address.
